# F1_窗口编排核心 阶段需求与验收

> 最后更新：2026-07-30 | 版本：v0.1
> 文档状态：草案
> 阶段定位：功能阶段（F1）；F0 + F0.1 Exit Gate 通过后开始

本文档是 F1_窗口编排核心 阶段的需求合同与验收依据。战略目标与边界以 [Tidy_开发路线图](../../Tidy_开发路线图.md) F1_窗口编排核心 为准；模块组织、状态机与 AX 行为细节参见 [Tidy 窗口管理 App 功能列表](../../Tidy%20窗口管理%20App%20功能列表.md)。

## 1. 目标（Goal）

F1_窗口编排核心 的目标是：

1. **完整闭环可用**：2～9 窗口排列 → 字母选择 → 临时放大 → 还原，核心流程在 Tier A App 上稳定工作；
2. **生产级健壮性**：AX 失败降级、Space 切换自动还原、超时还原、目标 App 退出恢复、App 切换 Session 保留；
3. **核心恢复指标稳定**：还原成功率 ≥ 99%、排列时间 P95 ≤ 800ms。

P0 探针已实现核心闭环并验证可行性。F1 在此基础上补充生产级功能和健壮性。

## 4. 功能需求（FR）

### FR-F1-001 AX 失败时原位置标签降级

- **描述**：排列时若个别窗口 AXSetFrame 失败，该窗口保留在原位置，仍显示字母标签供用户选择。
- **预期结果**：
  - 失败窗口不阻塞其他窗口排列
  - 失败窗口数超过半数时终止本次编排
  - 失败窗口原位置显示标签
- **现有基础**：P0 已实现"跳过 + >50% 终止"策略，需补充"原位置标签"。

### FR-F1-002 Space 切换自动还原

- **描述**：selecting 或 working 阶段，用户切换到其他 Space 时，自动触发还原。
- **预期结果**：
  - selecting 阶段切 Space → 还原所有窗口到原位置 → idle
  - working 阶段切 Space → 还原所有窗口到原位置 → idle
- **实现方式**：监听 NSWorkspace.activeSpaceDidChangeNotification。

### FR-F1-003 超时还原

- **描述**：selecting 阶段 30 秒无输入时，自动还原。
- **预期结果**：
  - 进入 selecting 时启动 30 秒计时器
  - 用户按有效键时重置计时器
  - 超时后还原所有窗口 → idle
- **配置**：超时时间默认 30 秒（F1.6 后可配置）。

### FR-F1-004 目标 App 退出尽力恢复

- **描述**：编排中目标 App 退出时，尽力恢复已排列的窗口。
- **预期结果**：
  - 监听 NSWorkspace.didTerminateApplicationNotification
  - 退出的 App PID == frontmostPID 时触发还原
  - 还原失败时记录日志，不崩溃

### FR-F1-005 App 切换 Session 保留

- **描述**：working 阶段用户切换到其他 App 时，不自动还原；返回后继续 working 状态。
- **预期结果**：
  - working 阶段切到其他 App → 保持 working 状态（不还原）
  - 切回目标 App → 仍在 working 状态
  - selecting 阶段切到其他 App → 保持 selecting 状态（不还原）

## 6. 验收标准（AC）

### AC-F1-001 完整闭环可用

- **Given** 前台 App 有 2～9 个可见窗口；
- **When** 触发热键 → 字母选择 → 最大化 → 再次触发热键还原；
- **Then** 排列 → 选择 → 最大化 → 还原全流程正常工作；
- **覆盖**：P0 核心闭环回归。

### AC-F1-002 AX 失败降级

- **Given** 排列时某窗口 AXSetFrame 失败；
- **When** 排列完成；
- **Then** 失败窗口保留原位置且显示标签；失败超过半数时终止编排；
- **覆盖**：FR-F1-001。

### AC-F1-003 Space 切换自动还原

- **Given** selecting 或 working 阶段；
- **When** 用户切换到其他 Space；
- **Then** 自动还原所有窗口到原位置 → idle；
- **覆盖**：FR-F1-002。

### AC-F1-004 超时还原

- **Given** selecting 阶段；
- **When** 30 秒无输入；
- **Then** 自动还原 → idle；
- **覆盖**：FR-F1-003。

### AC-F1-005 目标 App 退出恢复

- **Given** 编排中目标 App 退出；
- **When** 收到 App 终止通知；
- **Then** 触发还原；还原失败时记录日志不崩溃；
- **覆盖**：FR-F1-004。

### AC-F1-006 App 切换 Session 保留

- **Given** working 阶段；
- **When** 切换到其他 App；
- **Then** 保持 working 状态；切回后仍在 working；
- **覆盖**：FR-F1-005。

### AC-F1-007 Exit Gate 通过

- **Given** AC-F1-001 至 AC-F1-006 全部通过；
- **Then** F1 Exit Gate 通过，完整闭环可用，允许进入 v0.1 Pilot；
- **覆盖**：全部 FR 与 NFR。
