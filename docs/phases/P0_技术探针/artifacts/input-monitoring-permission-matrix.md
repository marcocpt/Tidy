## 1. 验证目标

1. CGEventTap 创建（`.cgSessionEventTap` + `.defaultTap`）
2. 键盘事件接收
3. 事件消费（拦截后不传递）

## 4. 验证步骤

每种权限组合的验证步骤：

1. 在"系统设置 > 隐私与安全性"中配置目标权限组合
2. 重启 Tidy 探针（确保权限状态被正确读取）
3. 触发 CGEventTap 创建：
   - 调用 `EventTapManager.startTap`
   - 观察返回值（true/false）
   - 查看 `os_log` 输出
4. 若创建成功，验证键盘事件接收：
   - 按下字母键
   - 观察是否收到事件回调
5. 若能接收事件，验证事件消费：
   - 在回调中返回 `false`（不传递事件）
   - 观察事件是否被消费（其他 App 不收到）
6. 记录结果与证据（日志、截图）
