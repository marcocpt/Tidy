## P0 Exit Gate 缺口汇总

基于 2026-07-29 测试运行结果（35 个测试全部通过），P0 Exit Gate 仍存在以下缺口：

### 必须补齐的硬门槛（阻塞 Exit Gate）

| AC | 缺口类型 | 需要的行动 |
|---|---|---|
| AC-P0-003 | 测试缺失 + 真实验证 | 编写 AXSetFrame 成功率测试 + 在 Tier A App 上手动验证 ≥ 99% |
| AC-P0-011 | 性能验证 | 在 M1 Pro 或同等机器上对 2/5/9 窗口各测 20 次，统计 P95 ≤ 800ms |
| AC-P0-014 | 兼容性矩阵 | 在 Xcode/VSCode/Finder/Safari/Chrome 上完成 2/5/9 窗口验证 |
| AC-P0-015 | 还原成功率 | 在真实 App 上验证还原成功率 ≥ 99% |
| AC-P0-017 | Tier B 证据 | 在 JetBrains/Office/Adobe 上完成验证并标注 PASS/LIMITED/LABEL_ONLY/UNSUPPORTED |

### 建议补齐的单元测试（不阻塞但提升覆盖）

## 说明

- 测试类型 `Unit`：可在 XCTest 中自动执行的单元/集成测试
- 测试类型 `Performance`：需要多次运行并统计 P95 的性能测试
- 测试类型 `Compatibility`：需要在特定 App 上手动执行的兼容性验证，结果记录到 `artifacts/`
- AC-P0-016（Exit Gate）是聚合判定，不单独设计测试用例
- 兼容性测试结果保存到 `docs/phases/P0_技术探针/artifacts/`
- 证据列中的测试方法名对应 `Tests/TidyCoreTests/` 和 `Tests/TidyUITests/` 下的实际测试方法
