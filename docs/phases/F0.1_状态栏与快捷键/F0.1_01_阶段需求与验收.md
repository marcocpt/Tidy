# F0.1_状态栏与快捷键 阶段需求与验收

> 最后更新：2026-07-30 | 版本：v0.1
> 文档状态：草案
> 阶段定位：功能阶段（F0.1）；F0 Exit Gate 通过后开始

本文档是 F0.1_状态栏与快捷键 阶段的需求合同与验收依据。战略目标与边界以 [Tidy_开发路线图](../../Tidy_开发路线图.md) F0.1_状态栏与快捷键 为准。

## 1. 目标（Goal）

F0.1_状态栏与快捷键 的目标是：

1. **状态栏图标反映简化状态**：未授权/空闲/编排中三种状态通过状态栏图标区分；
2. **下拉菜单提供基本交互**：Trigger Tidy + 退出 + 权限项（打开权限设置）；
3. **全局热键可触发**：Carbon 热键 ⌘⌥T 可触发编排 toggle，键码可配置；
4. **每个开发阶段可手动测试**：状态栏和热键作为后续阶段的测试入口。

## 4. 功能需求（FR）

### FR-F0.1-001 状态栏图标 3 状态

- **描述**：状态栏图标根据当前状态显示不同标识。
- **状态定义**：
  1. **未授权**：权限未完全授予时（AX 或 IM 任一 denied），显示 "!" 或灰色图标
  2. **空闲**：权限已授予、未在编排中，显示 "T"
  3. **编排中**：正在编排（selecting/working），显示 "●" 或高亮图标
- **预期结果**：用户可通过状态栏图标一眼看出当前状态。

### FR-F0.1-002 下拉菜单 3 项

- **描述**：点击状态栏图标显示下拉菜单，包含 3 项。
- **菜单项**：
  1. **Trigger Tidy**：触发编排 toggle（等同于热键）
  2. **权限设置...**：打开权限引导窗口（若已全部授权则灰显）
  3. **退出**：退出应用
- **预期结果**：菜单项可点击且触发对应行为。

### FR-F0.1-003 热键可配置入口

- **描述**：热键键码通过 HotkeyConfig 传入，支持后续配置化。
- **当前默认**：⌘⌥T（keyCode=17, modifiers=cmdKey|optionKey）
- **预期结果**：修改 HotkeyConfig 参数即可改变热键，无需修改注册逻辑。

## 5. 非功能需求（NFR）

### 5.1 性能

- 状态栏图标状态切换 ≤ 100ms（从状态变化到 UI 更新）
- 热键回调延迟 ≤ 50ms

### 5.2 可靠性

- 状态栏图标在权限变化、编排状态变化时自动更新
- 热键在前台任意 App 下均可触发

## 6. 验收标准（AC）

### AC-F0.1-001 状态栏图标反映 3 状态

- **Given** App 启动且权限/编排状态变化；
- **When** 权限未授权 → 已授权 → 编排中 → 空闲；
- **Then** 状态栏图标依次显示未授权/空闲/编排中/空闲标识；
- **覆盖**：FR-F0.1-001。

### AC-F0.1-002 下拉菜单 3 项可交互

- **Given** 状态栏图标可见；
- **When** 点击状态栏图标；
- **Then** 显示包含 Trigger Tidy / 权限设置... / 退出 的下拉菜单；每项可点击触发对应行为；
- **覆盖**：FR-F0.1-002。

### AC-F0.1-003 热键可触发

- **Given** 热键 ⌘⌥T 已注册；
- **When** 在任意前台 App 下按 ⌘⌥T；
- **Then** 触发编排 toggle 回调；
- **覆盖**：FR-F0.1-003。

### AC-F0.1-004 Exit Gate 通过

- **Given** AC-F0.1-001 至 AC-F0.1-003 全部通过；
- **Then** F0.1 Exit Gate 通过，状态栏可交互、热键可触发，允许进入 F1_窗口编排核心；
- **覆盖**：全部 FR 与 NFR。
