# F0_权限引导 阶段需求与验收

> 最后更新：2026-07-29 | 版本：v0.1
> 文档状态：草案
> 阶段定位：功能阶段（F0）；P0 Exit Gate 条件性通过后开始

本文档是 F0_权限引导 阶段的需求合同与验收依据。战略目标与边界以 [Tidy_开发路线图](../../Tidy_开发路线图.md) F0_权限引导 为准；P0 探针产出的 PermissionDetector 复用为本阶段基础。

## 1. 目标（Goal）

F0_权限引导 的目标是：

1. **首次启动时引导用户授权**：未授予辅助功能权限时，显示权限引导窗口，引导用户打开系统设置并授权；
2. **权限状态实时感知**：复用 P0 PermissionDetector，授权后自动关闭引导窗口并进入工作状态；
3. **Input Monitoring 权限引导**：根据 P0 探针的权限矩阵结果，若 CGEventTap 需要 Input Monitoring 权限，则在引导窗口中包含对应引导步骤；
4. **授权完成率可追踪**：记录用户从启动到完成授权的转化率，为后续优化提供数据基础。

## 3. Out of Scope

- 偏好设置窗口（F1.6）
- 状态栏完整交互（4 种图标状态、5 项菜单）（F0.1）
- 窗口编排功能（F1）
- 热键录制器（F1.6）
- 应用专属配置（F2）

## 4. 功能需求（FR）

### FR-F0-001 辅助功能权限引导窗口

- **描述**：首次启动 Tidy 时，若辅助功能权限未授予，显示权限引导窗口。
- **引导内容**：
  1. 说明 Tidy 需要辅助功能权限才能管理窗口
  2. 提供"打开系统设置"按钮，点击后跳转到系统设置 > 隐私与安全性 > 辅助功能
  3. 提供步骤说明（在辅助功能列表中找到并勾选 Tidy）
  4. 实时检测权限状态，授权后自动关闭引导窗口
- **预期结果**：用户按步骤完成授权后，引导窗口自动关闭，Tidy 进入正常工作状态。

### FR-F0-002 辅助功能权限状态监听

- **描述**：复用 P0 PermissionDetector，实时监听辅助功能权限状态变化。
- **预期结果**：
  - 权限从 denied → granted 时，引导窗口自动关闭
  - 权限从 granted → denied 时，引导窗口自动显示
  - 状态变化无需重启 App

### FR-F0-003 Input Monitoring 权限引导

- **描述**：根据 P0 探针的权限矩阵，若 CGEventTap 需要 Input Monitoring 权限，在引导窗口中增加对应引导步骤。
- **引导内容**：
  1. 说明 Tidy 需要输入监控权限才能拦截键盘选择窗口
  2. 提供"打开系统设置"按钮，跳转到系统设置 > 隐私与安全性 > 输入监控
  3. 提供步骤说明
- **预期结果**：Input Monitoring 权限授予后，对应引导步骤标记为已完成。

### FR-F0-004 权限状态与 UI 联动

- **描述**：引导窗口的视觉状态与权限状态保持同步。
- **预期结果**：
  - 两个权限均为 granted 时，引导窗口显示"全部授权完成"并自动关闭（延迟 1-2 秒让用户看到成功状态）
  - 任意权限为 denied 时，引导窗口保持显示
  - 授权步骤旁显示对勾（✓）或待完成标记

### FR-F0-005 授权完成率追踪

- **描述**：记录用户从启动到完成所有授权的转化事件。
- **事件类型**：
  - `permission_guide_shown`：引导窗口首次显示
  - `accessibility_granted`：辅助功能权限授予
  - `input_monitoring_granted`：Input Monitoring 权限授予
  - `all_permissions_granted`：全部权限授予
- **预期结果**：事件通过 os_log 输出，格式为 `tidy.permission event=<event_name>`，可用于后续分析。

## 5. 非功能需求（NFR）

### 5.1 性能

- 权限检测轮询间隔 ≤ 1 秒（复用 P0 PermissionDetector）
- 引导窗口显示延迟 ≤ 100ms（从权限状态变化到 UI 更新）

### 5.2 可靠性

- 权限状态检测不依赖轮询（使用 `AXIsProcessTrustedWithOptions`）
- 引导窗口不阻塞主线程

### 5.3 兼容性

- macOS 12 Monterey 及以上
- 适配深色/浅色模式

## 6. 验收标准（AC）

### AC-F0-001 辅助功能权限引导窗口显示

- **Given** Tidy 首次启动且辅助功能权限未授予；
- **When** App 完成启动；
- **Then** 显示权限引导窗口，包含引导步骤与"打开系统设置"按钮；
- **覆盖**：FR-F0-001。

### AC-F0-002 辅助功能授权后引导窗口关闭

- **Given** 权限引导窗口已显示且辅助功能权限未授予；
- **When** 用户在系统设置中授予辅助功能权限；
- **Then** 引导窗口检测到权限变化，标记辅助功能步骤为已完成，全部权限授予后自动关闭；
- **覆盖**：FR-F0-002、FR-F0-004。

### AC-F0-003 Input Monitoring 权限引导

- **Given** 辅助功能已授权但 Input Monitoring 未授权；
- **When** 权限引导窗口显示；
- **Then** 引导窗口包含 Input Monitoring 引导步骤；授权后标记为已完成；
- **覆盖**：FR-F0-003。

### AC-F0-004 权限撤销时引导窗口重新显示

- **Given** 所有权限已授予且引导窗口已关闭；
- **When** 用户在系统设置中撤销辅助功能权限；
- **Then** 引导窗口重新显示；
- **覆盖**：FR-F0-002。

### AC-F0-005 授权完成率追踪

- **Given** 权限引导流程执行；
- **When** 用户完成各步骤授权；
- **Then** os_log 输出 `tidy.permission` 事件，事件序列完整；
- **覆盖**：FR-F0-005。

### AC-F0-006 Exit Gate 通过

- **Given** AC-F0-001 至 AC-F0-005 全部通过；
- **Then** F0 Exit Gate 通过，权限引导流程可用，允许进入 F0.1_状态栏与快捷键；
- **覆盖**：全部 FR 与 NFR。

## 7. 决策自由度（Decision Freedom）

### 7.1 F0 期间可自由决定的技术细节

- 引导窗口的具体布局与文案（不要求与 Macim 完全一致，仅参考其设计理念）
- 引导窗口的动画效果
- Input Monitoring 检测的具体实现方式
- 授权完成率追踪的存储方式（P0 阶段仅 os_log，不要求持久化）

### 7.2 F0 期间需要 ADR 的决策

- 权限引导窗口的架构位置（TidyUI vs TidyApp）
- 权限状态管理方式（单例 vs 依赖注入）
