# F0_权限引导 设计文档

> 最后更新：2026-07-29 | 版本：v0.1
> 文档状态：草案
> 阶段定位：功能阶段 F0，对应 [F0_01_阶段需求与验收](F0_01_阶段需求与验收.md)

## 1. 架构

### 1.1 模块依赖

```
TidyApp → TidyUI → TidyCore
```

- **PermissionDetector**（TidyCore，P0 已实现）：AX 权限状态查询与监听
- **PermissionGuideWindow**（TidyUI，F0 新增）：权限引导窗口 UI
- **InputMonitoringDetector**（TidyCore，F0 新增）：Input Monitoring 权限检测
- **TidyAppDelegate**（TidyApp，F0 修改）：注入权限检测器，控制引导窗口生命周期

### 1.2 数据流

```
App 启动
  → PermissionDetector.startMonitoring()
  → InputMonitoringDetector.startMonitoring()
  → 检查权限状态
  → 任意权限 denied → 显示 PermissionGuideWindow
  → 全部权限 granted → 延迟 1.5s 后关闭 PermissionGuideWindow
  → 权限变化 → 更新 PermissionGuideWindow 状态
```

### 1.3 不变量

- **INV-F0-001**：PermissionGuideWindow 的显示状态与权限状态严格同步（任意 denied → 显示，全部 granted → 可关闭）
- **INV-F0-002**：PermissionDetector 实例唯一（单例或由 TidyAppDelegate 持有）
- **INV-F0-003**：权限引导窗口不阻塞主线程（UI 操作在主线程，权限检测在后台定时器）

## 2. 模块设计

### 2.1 PermissionGuideWindow（TidyUI）

**职责**：显示权限引导 UI，包含辅助功能和 Input Monitoring 两个引导步骤。

**接口**：

```swift
public protocol PermissionGuideShowing: AnyObject {
    /// 显示权限引导窗口
    /// - Parameters:
    ///   - accessibilityStatus: 辅助功能当前权限状态
    ///   - inputMonitoringStatus: Input Monitoring 当前权限状态
    func showGuide(
        accessibilityStatus: AccessibilityPermissionStatus,
        inputMonitoringStatus: InputMonitoringPermissionStatus
    )
    /// 更新权限状态
    func updateStatus(
        accessibilityStatus: AccessibilityPermissionStatus,
        inputMonitoringStatus: InputMonitoringPermissionStatus
    )
    /// 关闭引导窗口
    func closeGuide()
}
```

**UI 布局**（参考 Macim F0 设计）：

```
┌─────────────────────────────────────┐
│         Tidy 需要权限授权           │
│                                     │
│  辅助功能权限                       │
│  ✓ Tidy 需要辅助功能权限来管理窗口  │
│    [打开系统设置]                   │
│                                     │
│  输入监控权限                       │
│  ○ Tidy 需要输入监控权限来拦截按键  │
│    [打开系统设置]                   │
│                                     │
│  授权完成后将自动开始工作           │
└─────────────────────────────────────┘
```

**设计要点**：
- 使用 SwiftUI 构建引导窗口内容
- 通过 NSWindow 包装（NSPanel 不适合，因为需要接收鼠标事件）
- 窗口居中显示，固定大小（约 400×300 points）
- 深色/浅色模式自适应

### 2.2 InputMonitoringDetector（TidyCore）

**职责**：检测 Input Monitoring 权限状态。

**接口**：

```swift
public enum InputMonitoringPermissionStatus: Sendable, Equatable {
    case granted
    case denied
    case notRequired  // 不需要此权限（如 macOS 12 不强制要求）
}

public final class InputMonitoringDetector: ObservableObject {
    @Published public private(set) var status: InputMonitoringPermissionStatus

    public init()
    public static func checkPermission() -> InputMonitoringPermissionStatus
    public func startMonitoring(interval: TimeInterval)
    public func stopMonitoring()
}
```

**实现方式**：
- 尝试创建 CGEventTap，若成功则权限已授予，立即销毁测试 tap
- 若失败（返回 NULL），检查错误码判断是权限缺失还是其他原因
- 轮询检测状态变化（与 PermissionDetector 类似）

### 2.3 权限引导流程控制（TidyAppDelegate）

**修改 TidyAppDelegate.applicationDidFinishLaunching**：

```swift
func applicationDidFinishLaunching(_ notification: Notification) {
    // ... 现有依赖构建 ...

    // 权限检测与引导
    permissionDetector.startMonitoring()
    inputMonitoringDetector.startMonitoring()

    if needsPermissionGuide() {
        showPermissionGuide()
    }

    // 订阅权限状态变化
    permissionDetector.statusPublisher.sink { [weak self] status in
        self?.handlePermissionChange()
    }

    inputMonitoringDetector.statusPublisher.sink { [weak self] status in
        self?.handlePermissionChange()
    }
}
```

## 3. 状态管理

### 3.1 引导窗口状态

```
hidden → showing → completed → hidden
                ↘ showing（权限撤销时回到 showing）
```

- `hidden`：初始或授权完成后
- `showing`：权限引导窗口可见
- `completed`：全部权限已授予，延迟关闭中

### 3.2 权限步骤状态

每个引导步骤有三种视觉状态：
- 待完成（○）：权限未授予
- 已完成（✓）：权限已授予
- 进行中（动画）：用户点击了"打开系统设置"按钮

## 5. os_log 埋点

权限事件日志（对应 FR-F0-005）：

```swift
os_log("tidy.permission event=%{public}@ accessibility=%d input_monitoring=%d",
       log: permLog, type: .default,
       eventName, accessibilityGranted ? 1 : 0, inputMonitoringGranted ? 1 : 0)
```

事件名称：
- `permission_guide_shown`
- `accessibility_granted`
- `input_monitoring_granted`
- `all_permissions_granted`
