# ADR-0004：窗口操作仅使用辅助功能公开接口

- **状态**：已批准
- **关联不变量**：INV-005

## 上下文（Context）

Tidy 需要枚举和操作其他应用的窗口。系统提供了公开的辅助功能接口和未文档化的私有系统调用。私有调用可能在系统版本更新时失效，且使用私有调用可能导致应用被拒上架。

## 决策（Decision）

所有窗口枚举和操作必须通过系统辅助功能公开接口完成。禁止使用任何私有系统调用或未文档化的系统内部接口。

## 影响（Consequences）

- 应用兼容性随系统更新更稳定
- 部分应用的窗口操作可能受限（需通过兼容性矩阵记录）
- 未来可以上架应用商店
