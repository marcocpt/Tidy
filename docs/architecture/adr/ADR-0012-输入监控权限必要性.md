# ADR-0012：输入监控权限必要性

- **状态**：候选（待评审）
- **关联不变量**：INV-007

## 上下文（Context）

输入拦截（CGEventTap）在某些 macOS 版本上可能需要 Input Monitoring / Event Access 权限。这与辅助功能权限是独立的权限。如果需要额外权限，将增加首次使用引导的复杂度。

## 决策（Decision）

待 P0 探针验证。需要确认在目标平台上 CGEventTap 是否需要 Input Monitoring 权限，以及是否有替代方案。

## 影响（Consequences）

待评审确认后补全。
