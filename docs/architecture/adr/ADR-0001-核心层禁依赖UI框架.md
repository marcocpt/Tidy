# ADR-0001：核心层禁依赖 UI 框架

- **状态**：已批准
- **关联不变量**：INV-001

## 上下文（Context）

Tidy 需要清晰的核心逻辑与 UI 分离。窗口枚举、布局算法、状态机和编排协调是纯逻辑，不应该因为 UI 框架的变化而受影响。如果核心逻辑依赖了 UI 框架，将导致无法独立测试核心功能，也无法在不影响核心逻辑的情况下更换 UI 实现。

## 决策（Decision）

核心逻辑层（TidyCore）永不导入或链接任何 UI 框架。所有窗口枚举、布局算法、状态机逻辑和编排协调属于纯逻辑层，不得直接或间接依赖窗口覆盖层、状态栏或偏好窗口模块。

## 影响（Consequences）

- 核心逻辑可以独立测试，无需启动 UI
- UI 层可以独立替换而不影响核心逻辑
- 编译器级别的保障：核心层编译目标不链接 UI 框架
